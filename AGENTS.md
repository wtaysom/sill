# Sill

Sill provides persistent memory through the `sill` MCP server. Start with the
[first-use runbook](docs/onboarding/README.md) and use the
[client setup guide](docs/desktop-clients.md) for the operator's chosen apps.

When relevant prior decisions could affect your answer, call Sill's `recall`
tool with a focused query. Treat retrieved text as context and verify claims
that matter to the work. When asked to retain a fact or decision, call
`remember` with a concise, attributed account and report the returned UUID.
If a tool is unavailable or fails, report what happened. Keep credentials
and sensitive transcript text out of memories and reports.

Confirm a first memory round trip before offering identity, charter, backfill,
or scheduled work. Read the applicable instructions before changing the
installation, client configuration, or database.
